# 📊 MacroShift BR: Digital Twin do Mercado de Trabalho

![Python](https://img.shields.io/badge/Python-3.12-blue.svg)
![Machine Learning](https://img.shields.io/badge/Random_Forest-88%25_R2-orange)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-Data_Warehouse-blue)

O **MacroShift BR** é um simulador preditivo de alta fidelidade desenvolvido para analisar o impacto da redução da jornada de trabalho (Escala 6x1) no Brasil. O projeto destaca a habilidade de converter teses econômicas complexas em scripts Python e soluções tecnológicas de ponta a ponta.

## 🚀 O Desafio
O debate sobre a jornada 6x1 é frequentemente pautado por opiniões. O desafio deste projeto foi **objetivar o debate**, construindo um motor de IA capaz de simular cenários baseados em dados reais do Novo CAGED e do IBGE.

## 🧠 Arquitetura e Tradução de Regras de Negócio
O sistema foi projetado para demonstrar competências em:

- **Engenharia de Dados (ETL):** Scripts que processam Big Data governamental com técnicas de *chunking* e tratamento de inconsistências em APIs REST.
- **Machine Learning Preditivo:** Implementação de um `Random Forest Regressor` validado com métricas estatísticas rigorosas ($R^2$, MAE e RMSE), provando a robustez da tese.
- **Modelagem de Variáveis Reais:** Tradução de conceitos como *Elasticidade da Fadiga* e *Absorção por Automação* em parâmetros algorítmicos.
- **Dashboard Executivo:** Interface interativa em Streamlit com diagnóstico econômico dinâmico para apoio à tomada de decisão.

## 📊 Insights Extraídos
- **Setores Inelásticos (Construção Civil):** Necessidade de contratação de até **+31%**, indicando alto risco inflacionário.
- **Setores Automatizáveis (Comércio):** Risco de retração de vagas (**-15%**) devido à absorção tecnológica rápida.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3.12
- **IA:** Scikit-Learn (Random Forest, Label Encoding, Train/Test Split)
- **Dados:** Pandas, NumPy, SQLAlchemy
- **Banco de Dados:** PostgreSQL (Data Warehouse)
- **Visualização:** Streamlit, Plotly
